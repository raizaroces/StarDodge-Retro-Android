# StarDodge - 2D Retro Arcade Game

A classic 2D survival/dodging game developed as an academic project for our 2nd Year coursework. Built natively in Android Studio using Java/Kotlin with custom canvas or view-based rendering loops.

## Features

- **Interactive On-Screen D-Pad:** Directional controls (Up, Down, Left, Right) to navigate the player entity in real time.
- **Real-Time Gameplay Loop:** Dynamic projectile spawning that challenges the player to dodge incoming obstacles.
- **Game State Management:** Includes functional Start, Pause, and Game Over logic with toast notifications.
- **Score & Survival Timer:** Live tracking of player score and total elapsed time during active gameplay.
- **Pixel Art Aesthetic:** Space-themed retro visual design complete with custom control pads and pixel font displays.
